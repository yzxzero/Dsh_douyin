# Minetest / Luanti 肥鱼海底建造计划

这是创造模式的试玩世界，包含预置海底玻璃穹顶和三张可投票蓝图：海底宫殿、玻璃鱼塘、海底花园。模组按固定蓝图逐块放置方块，没有生存采集、材料消耗或语言模型自由设计。鱼是装饰实体，未接入真实生态模拟。原生镜头在同一座建筑施工时保持位置和朝向固定，先用黄色框标出下一块，再约每 0.7 秒放置一个实际变化的方块，按地基、立柱、墙体、屋顶等阶段展示。镜头不再按正弦曲线来回巡游；它仍是固定蓝图自动搭建，不是自主探索的生存机器人。

每轮投票 30 秒：发“投票 宫殿”“投票 鱼塘”或“投票 花园”。每个观众显示名一票，可在截止前改票；同名观众共用一票。按未完成蓝图中的最高票建造；平票或无票按宫殿、鱼塘、花园顺序。建造中不接收下一轮选票。前三座主题建筑保留，完成后继续投票，在新空地扩建紧凑版本；目前另有 21 块扩建空地。无票时按宫殿、鱼塘、花园轮换。只有实际完成新建筑才加计数，扩建区满后才进入展示。

“暂停建造”“继续建造”控制投票倒计时与逐块建造，镜头也停止转场。接受建议须经游戏确认；投票不受全局十秒建议间隔限制。聊天模型依据真实游戏回传的已放方块数、完成建筑数、当前阶段及票数发言。

新直播世界在 `worlds/whale_ocean_live`；地图和建造进度都持久保存，退出后下次继续未完成蓝图。三座建筑的完整测试世界在 `worlds/whale_ocean_verified_demo`，另保留原测试世界 `worlds/whale_ocean`。测试验证了实际建造、重复改票、暂停、保存、重开和不重复增加建筑数。旧韦诺之战和 OpenTTD 目录保留。

画面采集使用 Windows Graphics Capture，仅捕获本项目启动的 Luanti 窗口，不抓整个桌面。需要 Windows 处于解锁状态，游戏窗口展开；锁屏或最小化时返回画面未就绪。采集只监听 `127.0.0.1:8869`。本机游戏仅绑定回环地址，不公布服务器。人物保留右下方位置、上移 14% 和游戏专用 1.65 倍大小。

源代码：`lib/luanti.mjs`、`lib/luanti-director.mjs`、`tools/luanti-window-capture.py`；世界模组为 `worldmods/whale_live`。Windows 采集依赖现有 Python 中的 `windows-capture 2.0.1`、NumPy、OpenCV。游戏日志是 `whale-game.log`，直播服务日志是 `data/luanti-server.log`。
